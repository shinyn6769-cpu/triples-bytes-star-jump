ENDLESS STAR JUMP

닉네임을 정하고 byteS를 골라서 출발!
1단계부터 순서대로 진행하며, 목숨이 0이 될 때까지 무한히 도전할 수 있어.

욕설·개인정보 대신 게임용 닉네임을 사용해줘.

📱 모바일: ◀ ▶ 이동 · 점프 2회 가능. ⌨️ 키보드: A/D 또는 ←/→, 스페이스/↑/W로 점프, P로 일시정지. 1단계를 깨면 자동으로 2단계로 넘어가며, 이후 난이도와 길이가 계속 증가해. 낭떠러지·움직이는 발판·적·가시를 조심! 장애물에 닿으면 목숨 -1 (SIGNAL LIVE 보호막이 있으면 1회 방어). 단계마다 이동속도가 증가해!

🌐 전체 이용자 공유 랭킹 연결

GitHub Pages만으로는 전 세계 이용자의 기록을 모을 수 없어. Supabase를 연결하면 모든 캐릭터의 점수를 한 랭킹에서 비교할 수 있어. 연결 전에는 이 기기의 기록만 표시돼.

관리자: 온라인 랭킹 연결 설정

공개용 publishable(또는 anon) 키만 입력해. service_role/secret 키는 절대로 입력하지 마. 공개 배포하려면 게임 HTML의 LEADERBOARD_CONFIG에도 동일한 값을 넣어야 모든 방문자에게 적용돼.

공식 byteS 이미지가 차단되면 상징 아이콘으로 대체돼. 이 게임은 tripleS 또는 MODHAUS 공식 게임이 아니야.
